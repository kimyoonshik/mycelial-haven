## 0. 전제 조건 (모든 안에 공통)

| 구분 | 조건 | 적용 |
|------|------|------|
| **보안** | 후가공(안정화·마감) 공정의 장비·약품·온도·시간은 절대 노출하지 않는다 | 후가공은 "빛이 지나간다", "선이 접힌다" 같은 **도식**으로만 표현. 실제 설비 영상은 쓰지 않음 |
| **소재의 진실** | 순수 균사 매트는 **가죽처럼** 움직인다 (접히고, 휘고, 결이 빛을 받는다). 쉬폰처럼 펄럭이지 않는다 | B2B 구매자(태너리·브랜드 소재팀)는 거동을 보고 핸드필을 판단한다. 실물과 다른 거동을 보여 주면 샘플 단계에서 신뢰를 잃는다 → 역동성은 **슬로모션 + 모델의 움직임 + 조명**으로 만든다 |
| **호스팅** | 정적 호스팅(Apache 등)에 그대로 올라가야 한다 | 히어로 영상은 **데스크톱 ≤ 4 MB, 모바일 ≤ 2 MB**, 길이 12~18초 루프. 또는 영상 파일이 없는 브라우저 생성 방식 |
| **자동 재생 규칙** | 브라우저는 **무음**인 영상만 자동 재생한다 | 음악·내레이션에 기대지 않는 연출. 소리는 "재생" 버튼을 누른 사람에게만 |
| **접근성·성능** | 동작 줄이기 설정, 저사양 폰, 느린 회선 | 포스터 이미지가 먼저 뜨고 영상은 뒤에 로드. 동작 줄이기면 포스터만 |
| **이중 언어** | 영문 기본, 한글 토글 | 영상 안에 글자를 굽지 않는다. 문구는 HTML로 얹어 언어 토글에 따라 바뀜 |
| **운영 도구** | 론칭 후 교체 가능해야 함 | site.json 히어로에 영상(mp4/webm)·포스터·세로 버전 필드 추가, 운영 도구 업로드 한도 영상 30 MB (개발 필요, 1일) |

## 1. 제작 방식 3가지 비교

| | ① 실사 촬영 | ② 3D·모션그래픽 | ③ 브라우저 생성 (코드) |
|---|---|---|---|
| 임팩트 | 소재의 질감·사람의 감정 (가장 강함) | 보여 줄 수 없는 것을 보여 줌 (미세 구조, 공정 도식) | 매번 새로 그려져 살아 있는 느낌, 커서·스크롤에 반응 |
| 보안 | 촬영 범위를 통제하면 안전 | 도식화가 쉬움 (가장 안전) | 본질적으로 도식 (안전) |
| 비용 (대략) | 댄서 촬영 1일 + 후반: 800~2,500만 원 / 랩 타임랩스: 장비 50~150만 원 + 2~3주 배양 | 15초 하이브리드: 1,500~4,000만 원, 4~8주 | 내부 개발 2~3일 (추가 비용 없음) |
| 파일 용량 | 2~4 MB (압축 후) | 2~4 MB | **0 MB** (사진 11장 약 1 MB) |
| 교체·수정 | 재촬영 | 재렌더링 | 사진·문구만 바꾸면 됨 |
| 약점 | 일정·날씨·섭외 | 과하면 "CG 광고"처럼 보임 | 사람의 온기가 없음 → B안과 결합 |

> 결론: **하나로 고르지 말고 2막 구조로 결합**한다. 1막 "성장→원단"(③ 또는 ②+실사 타임랩스), 2막 "사람과 소재"(① 댄서). 출시 일정상 1막을 먼저 띄우고 2막을 촬영 후 교체한다.

## 2. 콘티

### A안 — "From Pot to Sheet" (포트에서 원단까지) · 15초 · 마이세라님 1안

하이브리드: 실사 매크로·타임랩스 + 3D 도식 + 실사 원단.

| 시간 | 화면 | 텍스트 (HTML 오버레이) | 제작 | 비고 |
|------|------|------|------|------|
| 0.0–1.5 | 암전. 접시 위 배지에 **균사 끝 한 가닥**이 빛을 받아 자라기 시작 (초근접) | — | 실사 매크로 (현미경 카메라) 또는 3D | 숨 멎는 첫 컷. 흰 가닥 하나만 |
| 1.5–5.0 | 카메라가 뒤로 빠지며 **포트 안 배지 전면에 균사가 퍼지는 타임랩스** (Day 1 → Day 14) | `Day 1 … Day 14` 숫자 | **실사 타임랩스** (랩에서 직접 촬영) | 가장 설득력 있는 장면. 배양실 설비는 프레임 밖 |
| 5.0–6.5 | 장갑 낀 손이 매트를 **포트에서 들어 올린다** — 한 장으로 떨어지는 순간 | — | 실사 | "수확" 컷. 배접 없이 한 장임을 증명 |
| 6.5–9.0 | 매트가 공중에 수평으로 떠서 **빛의 문 2개를 통과** (01 Stabilize, 02 Finish). 문을 지날 때마다 표면이 바뀜: 솜 → 매끈한 크림색 → 결이 생김 | `Stabilize` `Finish` 라벨만 | 3D 도식 | 장비·약품·수치 없음. 빛·입자·선만 |
| 9.0–12.0 | 완성 원단이 화면을 **가득 채우며 펼쳐지고**, 사광(raking light)이 지나가며 결이 드러남 → **12색이 물결처럼 지나감** | — | 실사 원단 + 3D 합성 | 반응성염료 12색 = 쇼핑몰 구성과 일치 |
| 12.0–15.0 | 원단이 반쯤 접힌 **제품 컷**(토트백 또는 손목 위 스와치)으로 랙포커스 | `Grown, not manufactured.` + CTA | 실사 | 루프: 결이 녹아 다시 0초의 균사 가닥으로 |

- 준비물: 배양 타임랩스는 **지금 시작해야** 4주 뒤 쓸 수 있다 (카메라 고정, 10분 간격, 14~21일, 조명 일정 고정, 포트 1개는 촬영 전용).
- 보안 체크: 배지 조성·접종 방법·배양 조건은 화면에 안 보임. 장갑·포트·매트만.

### B안 — "The Dancer · Ten Skins" (발레리나, 10번 변모) · 15초 · 마이세라님 2안

| 시간 | 화면 | 텍스트 | 제작 | 비고 |
|------|------|------|------|------|
| 0.0–2.0 | 검은 스튜디오, 헤이즈, 단일 톱라이트. 댄서는 실루엣. **Mycerra 한 장(150×100 cm)이 어깨에서 흘러내린다** — 가죽처럼 무겁게, 천천히 | — | 실사 120fps 슬로모션 | 첫 2초는 "이게 가죽인가?" |
| 2.0–12.0 | 같은 동작 프레이즈(턴 → 팔 들어 원단이 원을 그림 → 멈춤)를 반복. **턴마다 원단이 바뀐다**: CR-03 크로커다일 → HP-03 → MC-06 → MC-08 → MG-02 → BG-05 버건디 → MN-02 네이비 → SR-07 스칼렛 → IB-06 → MR-08 메리골드 | 우상단에 코드·이름 작게 | 실사 **10테이크 매치컷** (원단 10장 교체) | 10장 모두 **현재 판매 중 SKU** — 영상이 곧 카탈로그. CG 교체 없이 진짜 소재 |
| 12.0–15.0 | 마지막 턴에서 원단이 얼굴을 스치며 멈춤, 카메라가 원단 결로 밀고 들어감 | `Grown, not manufactured.` + CTA | 실사 | 루프: 결 → 암전 → 0초 |

- **물성에 대한 솔직한 판단:** 150×100 cm 매트는 가죽 두께라 **펄럭이지 않는다.** "펄럭임"을 CG로 만들면 소재 거동을 거짓으로 보여 주는 셈이다. 대신 **슬로모션에서 원단이 휘어지고 결이 빛을 받는 무게감**이 오히려 고급 가죽의 언어다. 꼭 가벼운 흐름이 필요하면 **얇은 두께 매트(샘플 단계에서 두께 결정 후)**로 테스트 컷을 먼저 찍어 본다.
- 촬영 전 **테스트 1시간**: 원단 1장, 폰 240fps, 어깨에 두르고 턴 3회. 이걸 보고 댄서 섭외 여부를 정한다.
- 섭외: 댄서 1명(현대무용/발레), 촬영감독 1, 조명 1, 스튜디오 반일, 원단 10장 (EM-01~04, RD-01~06 = 10장 정확히).

### C안 — "Living Surface" (브라우저가 그리는 성장) · 18.5초 · 시제품 완성

- 영상 파일 없이 **방문할 때마다 브라우저가 균사 성장을 새로 그린다.** 성장 → 안정화 빛 스윕 → 마감 스윕 → 원단 전면 → **표정 10종(실제 사진)** → 타이틀.
- 시제품: 마이세라님께 공유한 링크. 재생 조절·구간 이동 가능. 데스크톱 16:9, 휴대폰 4:5.
- 장점: 0 MB, 공정 완전 도식, 모든 화면에서 선명, 사진만 바꾸면 갱신, **A안의 6.5–12초 구간을 이걸로 대체할 수 있다.**
- 보완: 1막으로만 쓰고 2막(B안)을 붙이면 완성.
- 변형 C-2 **"균사가 로고를 쓴다"**: 균사 가닥이 자라 `Mycerra` 글자 모양으로 모이고, 글자 안이 가죽 결로 채워진 뒤 흩어진다. 브랜드 인트로용 (3초). 같은 엔진으로 제작 가능.

### D안 — "Scroll to Transform" (스크롤이 공정을 민다)

- 첫 화면이 고정되고, **방문자가 스크롤하는 만큼** 포트 → 매트 → 원단 → 제품으로 변한다 (Apple 제품 페이지 방식, 이미지 시퀀스 60~90프레임).
- 자동 재생 제약이 없고, 방문자가 "직접 만드는" 느낌. 모바일에서도 안정적.
- A안의 3D 렌더 프레임을 그대로 재사용 → A안을 만들면 D안은 덤.

### E안 — "Raw / Finished" (한 장면, 두 상태)

- 화면 왼쪽은 살아 있는 균사(매크로 루프), 오른쪽은 완성 가죽 결. 가운데 **경계선이 천천히 오가고**, 방문자가 드래그하면 직접 비교.
- 지금 가진 사진으로 **1일 안에** 제작 가능. 메시지가 가장 단순: "이것이 이것이 된다."
- 임팩트는 중간. 출시 임시안 또는 Technology 페이지 상단용.

| 장치 | 내용 | 비용 |

## 3. 추천 조합과 일정

**추천: 2막 히어로 (총 ~20초 루프)**
1. 1막 (0–8초): **C안 성장 → 원단** (A안의 실사 타임랩스가 준비되면 성장 구간만 실사로 교체)
2. 2막 (8–18초): **B안 댄서 10번 변모**
3. 마무리 (18–20초): 타이틀 + CTA, 루프

| 단계 | 기간 | 내용 | 결과 |
|------|------|------|------|
| 1 (지금 → 2주) | 촬영 없음 | C안 완성본 사이트 적용 + F 스와치 호버 + 운영 도구 영상 필드 | **출시 가능한 히어로** |
| 2 (지금 시작) | 2~3주 배양 | 랩 타임랩스 촬영 (포트 1개, 카메라 고정) | A안 실사 소스 |
| 3 (테스트 후) | 반일 테스트 → 1일 촬영 → 1주 후반 | B안 테스트 컷 → 댄서 촬영 | 2막 영상 |
| 4 | 1~2일 | 1막+2막 합치고 교체, 모바일 세로 버전 | 완성 |

## 4. 웹 적용 규격 (영상을 쓰는 경우)

| 항목 | 규격 |
|------|------|
| 파일 | MP4 (H.264, High, CRF 24~26) + WebM (VP9 또는 AV1). 둘 다 제공, 브라우저가 고름 |
| 해상도 | 데스크톱 1920×1080 (≤ 4 MB), 모바일 세로 1080×1350 (≤ 2 MB) — `<source media>`로 분기 |
| 길이 | 12~20초 seamless loop. 첫 프레임 = 마지막 프레임 |
| 포스터 | WebP 1920 폭, ≤ 150 KB. 첫 화면(LCP)은 포스터가 담당 |
| 속성 | `autoplay muted playsinline loop preload="metadata"`, 동작 줄이기면 포스터만 |
| 텍스트 | 영상에 굽지 않음. HTML 오버레이 (영/한 토글) |
| 호스팅 | `public/media/video/` 정적 파일, 캐시 1년(파일명에 버전). Apache는 Range 요청 기본 지원 → 추가 설정 없음 |
| 인코딩 예 | `ffmpeg -i src.mov -vf scale=1920:-2 -c:v libx264 -crf 25 -preset slow -movflags +faststart -an hero.mp4` |

## 6. 결정이 필요한 것 (open-items.md D절과 동일)

1. 2막 구조(C/A + B)로 갈지, 하나만 갈지
2. 랩 타임랩스를 지금 시작할 수 있는지 (포트 1개·카메라 자리)
3. 댄서 안: 가죽 같은 무게감(실사)으로 갈지, 펄럭임(CG 연출)을 원하는지 — 테스트 컷 먼저 권장
4. 예산 범위 (외주 없이 내부 + C안만 / 댄서 촬영까지 / 3D 외주까지)
5. 스와치 호버(F)를 히어로에 넣을지
