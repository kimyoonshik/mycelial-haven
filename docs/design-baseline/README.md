# 화면 구성 기준선 (승인 상태 고정)

> 확정: 2026-11-02 · 마이세라님 승인 ("전체 화면 구성이 좋아졌다, 변경되지 않도록 주의")
> 되돌림 지점: Git 태그 **`design-baseline-2026-11-02`**
> 자동 검사: `npm run build && npm run check:layout` (기준 데이터 `layout.json`)

---

## 1. 원칙

1. **글꼴·글자 크기·배치(한 줄에 몇 개)·색·섹션 순서는 마이세라님 승인 없이 바꾸지 않는다.**
2. 기능 추가·문구 수정·버그 수정 중에도 화면 구성이 바뀌면 안 된다. 커밋 전 매번 `check:layout` 을 실행한다.
3. 검사에서 차이가 나오면:
   - 의도하지 않은 변경 → 되돌린다.
   - 승인받은 변경 → `npm run check:layout -- --update` 로 기준선을 갱신하고, 아래 3장 표와 변경 이력에 기록한다.
4. 디자인 개선 아이디어는 **먼저 제안하고, 승인 후에만** 적용한다.

## 3. 고정된 배치 — 홈 화면

PC = 1440px · 확대 = 브라우저 확대로 화면 폭이 좁아진 상태(620px) · 휴대폰 = 390px

| 순서 | 섹션 | PC | 확대 | 휴대폰 |
|:---:|------|:---:|:---:|:---:|
| 1 | 히어로 (첫 화면, 항상 맨 위) | 제목 124px | 53px | 50px |
| 2 | 선언문 (Statement) | 72px | 35px | 35px |
| 3 | What / Why / How | 한 줄 3개 | 한 줄 3개 | 1개씩 |
| 4 | 소재 라이브러리 (12종) | **3개씩 4줄** | **3개씩 4줄** | 옆으로 넘겨 보기 |
| 5 | 공정 3단계 | 한 줄 3개 | 1개씩 | 1개씩 |
| 6 | Impact (수치 5개) | **윗줄 3 + 아랫줄 2** | **3 + 2** | 1개씩 |
| 7 | 쇼핑 분류 | **한 줄 4개** | **한 줄 4개** | 1개씩 |
| 8 | 컬렉션 | 한 줄 4개 | **2개씩 2줄** | 1개씩 |
| 9 | 대상 (브랜드·태너리) | 2개 나란히 | 1개씩 | 1개씩 |
| 10 | 회사 · News & Media | 2단, 소식 **2개씩** | 소식 **2개씩** | 1개씩 |

다른 페이지(소재·기술·임팩트·협업·쇼핑)도 영문·한글, 세 가지 폭 모두 `layout.json` 에 기록되어 있다 (총 36개 화면).

## 4. 화면이 달라질 수 있는 경우 (변경 아님)

| 경우 | 설명 |
|------|------|
| 브라우저 확대 | Ctrl + / − 로 확대하면 화면 폭이 줄어 "확대" 배치가 보인다. **Ctrl+0** 으로 100% 복귀 |
| 운영 도구 "페이지" 탭 | 섹션 순서·숨김을 마이세라님이 직접 바꾸면 그대로 반영된다 (히어로는 항상 맨 위로 고정) |
| 항목 수 변경 | 소식·수치·상품을 추가/삭제하면 줄 구성이 달라진다 (예: 수치 6개 → 3 + 3) |
