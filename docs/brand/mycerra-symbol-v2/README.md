# Mycerra™ 심볼 — 균사 M (V2) 벡터 원본

> 제작: 2026-11-06 · 세이브어스(주) · 상태: **시안 확정본(V2)** — 사이트 적용 전
> 형태: 양쪽 균사가 자라 봉우리에서 V자로 갈라지고, 가운데 노드에서 만나 M을 이룸

## 1. 파일 구성

| 폴더 | 형식 | 용도 |
|------|------|------|
| `SVG/` | SVG (벡터) | 웹사이트·Figma·Illustrator. **선을 면으로 변환(아웃라인)** 해 어디서 열어도 모양이 같음 |
| `SVG/…_editable-stroke.svg` | SVG (선) | 디자이너 편집용 — 선 굵기·색을 바로 바꿀 수 있는 원래 선 구조 (48 격자, 굵기 2.6) |
| `PDF/` | PDF (벡터) | 인쇄소 전달·Illustrator 열기·문서 삽입. 여백 없이 도형 크기 그대로 |
| `EPS/` | EPS (벡터) | 구형 인쇄·간판·각인(레이저) 업체용 |
| `PNG/` | PNG 2048px, 투명 배경 | 파워포인트·워드·SNS 등 벡터를 못 쓰는 곳 |

- 이름 끝 `_square` = 정사각 캔버스(여백 12%) — 앱 아이콘·파비콘·SNS 프로필용
- 이름 끝이 없는 것 = 도형에 꼭 맞춘 캔버스 — 로고 조합(심볼 + 글자)·인쇄용

## 2. 색상

| 파일 | 용도 | HEX | RGB | CMYK (참고값) |
|------|------|-----|-----|------|
| `gold` | 짙은 금색 (기본 · 밝은 바탕용) | #B57F22 | 181, 127, 34 | 0 / 30 / 81 / 29 |
| `gold-light` | 밝은 금색 (어두운 바탕·사진 위) | #E2A63C | 226, 166, 60 | 0 / 27 / 73 / 11 |
| `black` | 먹색 (흑백 인쇄) | #23211D | 35, 33, 29 | 0 / 6 / 17 / 86 |
| `white` | 흰색 (어두운 바탕 단색) | #FFFFFF | 255, 255, 255 | 0 / 0 / 0 / 0 |

> CMYK 는 화면색에서 계산한 참고값입니다. 명함·브로셔 인쇄 시 인쇄소에서 색 교정(교정쇄)을 받으세요. 금박·별색이 필요하면 인쇄소와 별도 지정합니다.

## 3. 사용 규칙

| 항목 | 기준 |
|------|------|
| 최소 크기 | 화면 16px · 인쇄 높이 5mm (그보다 작으면 갈래가 뭉개짐) |
| 여백 | 심볼 주변에 **노드(가운데 점) 지름 이상** 비워 둠 |
| 글자와 조합 | 'Mycerra™'(Cormorant Garamond) 왼쪽에 배치, 간격 = 글자 크기의 약 0.45배 |
| 금지 | 늘이기·눕히기·기울이기, 그림자·테두리 추가, 지정 외 색, 복잡한 사진 위에 대비 없이 올리기 |

## 4. 참고

- 사이트 헤더 적용은 마이세라님 승인 후 진행 (화면 구성 기준선 변경 기록 포함)
- 상표 출원 전 변리사를 통한 **유사 상표 선행조사** 권장 (같은 균사 소재 업계의 기존 심볼과 구분)
