## 5. 사이트와 연결

1. 페이지 주소 복사 (예: `https://www.linkedin.com/company/mycerra`)
2. 운영 도구 → **SEO** 탭 → **LinkedIn** 칸에 붙여넣기 → 저장 → 게시
3. 자동 반영: 사이트 바닥글 LinkedIn 아이콘 · 검색엔진 회사 정보(sameAs) · AI용 요약(llms.txt "Official channels")

## 6. 노출을 키우는 습관

- 마이세라님·직원 개인 프로필 **경력(Experience)**에 회사 페이지를 연결 (회사 로고가 프로필에 표시되고 팔로워 유입)
- 주 1회 게시: 소재 사진, 전시·인터뷰 소식, 성적서·인증 — 사이트 **소식** 탭에 올린 내용과 같은 주제로
- 전시(LINEAPELLE 등) 기간에는 부스 위치·사진을 당일 게시하고 방문 브랜드를 태그
