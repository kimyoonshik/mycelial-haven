# Mycerra 운영 도구 (CMS) 사용 설명서

> 론칭 후 상품·가격·크기·성적서·소식·검색 문구를 **코드 수정 없이** 추가·수정·삭제하는 도구입니다.
> 최종 갱신: 2026-10-31

---

## 1. 준비 (PC당 최초 1회)

1. **Node.js 설치:** [nodejs.org](https://nodejs.org)에서 LTS(20 이상) 버전을 설치합니다.
2. **Git 설치:** [git-scm.com](https://git-scm.com)에서 설치하고, GitHub 계정으로 로그인해 둡니다.
3. **소스 받기:** 아래 명령을 실행합니다.
   ```
   git clone https://github.com/kimyoonshik/mycelial-haven.git
   cd mycelial-haven
   git checkout feature/rea-site-cloner
   npm install
   ```
   - 출시 전까지는 작업 브랜치(`feature/rea-site-cloner`)를 씁니다. 출시 후 main으로 합치면 세 번째 줄은 필요 없습니다.

## 2. 실행

### 더블클릭으로 열기 (권장)

저장소 폴더 안의 실행 파일을 더블클릭하면 **최신 내용 받기 → 필요하면 설치 → 운영 도구 실행 → 브라우저 자동 열림**까지 한 번에 됩니다.

| PC | 파일 | 바탕화면에 두는 방법 |
|----|------|---------------------|
| Windows | `Mycerra-CMS-Windows.bat` | 파일을 마우스 오른쪽 클릭 → 보내기 → **바탕 화면에 바로 가기 만들기** |
| Mac | `Mycerra-CMS-Mac.command` | 파일을 선택하고 `Option + Command`를 누른 채 바탕화면이나 Dock으로 끌어 **가상본** 만들기 |

- 실행 파일 자체를 바탕화면으로 옮기지 마세요. 저장소 폴더 안에 있어야 동작합니다.

### 사이트만 보기 (편집 없이)

| PC | 파일 | 결과 |
|----|------|------|
| Windows | `Mycerra-Site-Windows.bat` | 최신 내용으로 사이트를 만들어 **http://127.0.0.1:8080/** 에 띄우고 브라우저를 엶 |
| Mac | `Mycerra-Site-Mac.command` | 같음 |

- 실제 공개 사이트(웹호스팅에 올라갈 파일)와 똑같은 화면입니다. 관리 화면은 포함되지 않습니다.
- `127.0.0.1`은 "이 PC"라는 뜻이라, **실행 파일 창이 켜져 있는 동안에만** 주소가 열립니다.
- 운영 도구가 이미 켜져 있으면 새로 만들지 않고 브라우저만 엽니다 (그때 화면은 저장 내용이 바로 반영된 편집용 사이트).
- **휴대폰에서 보기:** 실행 창에 나오는 `http://192.168.x.x:8080/` 주소(또는 QR 코드)를 PC와 **같은 Wi-Fi**에 연결된 휴대폰에서 엽니다.
  - 처음 실행 때 Windows 보안 창이 뜨면 **[허용]** (개인 네트워크). 사내 Wi-Fi가 "공용 네트워크"로 설정돼 있으면 열리지 않으니 Windows 설정 → 네트워크 → 해당 Wi-Fi → **개인 네트워크**로 변경.
  - 같은 사내망의 다른 PC·휴대폰도 볼 수 있습니다 (공개 사이트와 같은 내용만, 관리 화면은 없음).
  - 운영 도구가 켜져 있으면 휴대폰에서는 열리지 않습니다 (운영 도구는 보안상 이 PC에서만 열림).
  - 사무실 밖(모바일 데이터)에서는 열리지 않습니다. 외부에서는 Claude 미리보기 링크를 쓰거나, 호스팅 이전 후 www.saveearth.kr로 봅니다.
- Mac에서 처음 열 때 "확인되지 않은 개발자" 경고가 뜨면: 파일을 Control+클릭 → **열기** → 열기.
- 끝낼 때: 검은 창(터미널)을 닫거나 `Ctrl + C` (Mac은 `Control + C`).

### 명령어로 열기

```
git pull
npm run cms
```

- 브라우저에서 터미널에 표시된 **http://127.0.0.1:8080/admin/content** 로 접속합니다.
- **보안:** 이 PC에서만 열리고, 실행할 때마다 새 보안 토큰이 만들어집니다. 다른 PC나 다른 웹사이트에서는 접근할 수 없습니다.
- **종료:** 터미널에서 `Ctrl + C`를 누릅니다.
- **수정 전 최신 내용 받기:** 실행 파일은 자동으로 받습니다. 명령어로 열 때는 매번 `git pull`을 먼저 실행합니다(다른 담당자의 변경을 받아 옵니다).

## 3. 탭별 기능

| 탭 | 할 수 있는 일 |
|----|-------------|
| **페이지** | 홈·소재 라이브러리·기술·임팩트·협업 안내·쇼핑몰 각 페이지의 **섹션 순서 변경(↑↓)·숨기기/보이기(눈 아이콘)**, 섹션별 **문구(영/한) 수정**, **게시된 사진 교체(업로드)**. 오른쪽 미리보기가 저장할 때마다 해당 섹션 위치로 갱신됨. **공통 콘텐츠**: 소재 라이브러리 12종(사진·이름·설명·대표색), 공정 3단계 사진·설명, 컬렉션 제품 사진, 임팩트 수치, 원산지 추적, 성능 특성, 마감 옵션, 향후 플랫폼, 공급 조건, 자료 목록, 바닥글 |
| **상품** | 가공 조건별 목록·검색<br>**추가:** 조건 버튼을 누르면 상품코드가 자동으로 붙음 (예: EM-21)<br>**복제·삭제**, 이름·설명(영/한) 수정<br>**사진:** 업로드 또는 기존 사진 선택<br>**판매 상태:** 판매중 / 준비중<br>**판매 크기** 선택 |
| **크기·가격** | **가공 조건별 sqft 단가·HS 코드:** 순수 / 엠보 적용 / 반응성염료 적용 / 최종 피니시 적용 (HS 코드는 인보이스에 조건별로 인쇄)<br>**원단 크기:** 정규 1·2·3 (장 단위) + 스와치 브로셔 (30×30 cm × 세트당 장수, 세트 단위) — 추가·수정 가능<br>**장당·세트당 가격표:** 빈칸이면 면적 × 단가로 자동 계산, 값을 넣으면 그 칸만 개별 가격<br>**주문 규칙:** 최소 sqft, 개인 주문 상한, 주문당 브로셔 최대 세트 수, 배송비<br>**판매자 정보:** 인보이스에 인쇄 |
| **성적서** | 시험 결과·시험기관·시험일 입력, **성적서 PDF 업로드**. 결과를 입력하면 사이트의 "보고 완료" 집계에 반영됨 |
| **소식** | 추가(맨 위)·수정·삭제·순서 변경 (위쪽이 홈에 먼저 표시) |
| **SEO** | 페이지별 검색 결과 제목·설명 (영/한), 사이트 주소, **SNS 계정 주소**(바닥글 아이콘 자동 표시), **검색엔진 소유 확인 코드**(Google·네이버·Bing) — 자세한 절차는 [SEO 안내](./seo.md) |
| **게시** | 검사 → 빌드 → **게시** (변경 내용 메모 입력 필수) |

### 작업 흐름

```
수정 → [저장] → (사이트 보기 탭 새로고침으로 확인) → [게시] 탭 → 검사 → 빌드 → 메모 입력 → [게시]
```

- **저장:** 저장할 때마다 전체 데이터를 검사합니다. 오류가 있으면 **저장되지 않고** 빨간 목록으로 이유를 보여 줍니다.
  - 예: "판매 중 상품에는 이미지가 필요합니다", "최소 물량은 개인 주문 상한보다 작아야 합니다"
- **백업:** 저장할 때마다 이전 파일이 `.cms-backups/` 폴더에 자동으로 보관됩니다.
- **게시:** 변경 파일(`src/content/data`, `public/media`)만 GitHub에 올립니다. 연결된 호스팅(Lovable·Netlify 등)이 자동으로 새 버전을 배포합니다.
- **FTP 호스팅:** "빌드" 후 `dist/` 폴더를 업로드합니다([호스팅 가이드](./hosting.md)).

### 페이지 편집 요령

- 왼쪽에서 페이지 → 섹션을 고르면 가운데에 그 섹션의 입력 칸이 나타납니다. 영문·한글은 항상 함께 채워야 저장됩니다.
- 목록형 내용(항목·단계·컬렉션 등)은 항목별로 ↑↓ 순서 변경, 삭제, "항목 추가(마지막 항목 복사)"가 됩니다.
- 사진 칸의 **업로드**로 새 사진을 올리면 바로 선택됩니다. 기존 사진 목록에서 골라 바꿀 수도 있습니다.
- 섹션은 디자인과 짝을 이루므로 **새로 만들거나 지울 수는 없고**, 순서 변경과 숨기기만 됩니다. 새 섹션 형태가 필요하면 개발 요청을 합니다.
- 홈의 "첫 화면"을 숨기거나 순서를 바꾸면 상단 메뉴가 자동으로 일반(불투명) 형태로 바뀝니다.
- 내용이 다른 곳에서 오는 섹션(예: 공정 3단계)을 고르면 어디서 편집하는지 안내가 나옵니다.
- 미리보기는 **저장한 내용** 기준입니다. 저장 전 변경은 상단 탭의 ● 표시로 알 수 있습니다.

## 4. 사진·PDF 규칙

| 항목 | 규칙 |
|------|------|
| 사진 형식 | webp(권장)·jpg·png, 8MB 이하, 긴 변 1920px 이하 권장 |
| PDF | 성적서만, 8MB 이하 |
| 파일명 | 영문 소문자·숫자·하이픈으로 자동 변환 (예: `Saffron Grain.webp` → `saffron-grain.webp`) |
| 같은 이름 | 덮어쓸지 확인 창이 뜸 |
| 저장 위치 | `public/media/site/` (페이지 사진), `public/media/products/` (상품 사진), `public/media/reports/` (성적서) |

## 5. 자주 묻는 문제

| 증상 | 해결 |
|------|------|
| "운영 도구는 npm run cms 로 실행한 화면에서만…" | `npm run dev`가 아니라 `npm run cms`로 실행 |
| 저장 시 "invalid token" | 터미널에서 서버가 재시작됨 → 브라우저 새로고침 |
| 게시 실패 (push rejected) | 운영 도구를 닫고 실행 파일을 다시 열기 (자동으로 `git pull`) 후 다시 게시 |
| 실행 파일 창에 "최신 내용을 받지 못했습니다" | 인터넷·GitHub 로그인 확인. 게시하지 않은 수정이 있으면 먼저 게시 |
| 실수로 저장함 | `.cms-backups/`의 직전 파일을 `src/content/data/`에 덮어쓰기, 또는 `git checkout -- src/content/data` (게시 전) |
| 빌드 실패 | 게시 탭 "검사"의 오류 목록을 고친 뒤 다시 빌드 |

## 6. 운영 도구로 바꿀 수 없는 것 (개발 필요)

- 새로운 형태의 섹션 추가, 섹션 안의 배치·디자인 변경 (`src/pages/site/*.tsx`)
- 메뉴 이름, 버튼·필터 같은 화면 조작 문구
- 결제·주문 흐름, 인보이스 양식
- 송금 계좌 정보: 보안상 `src/content/bankAccounts.ts`에서 직접 수정. 공개 사이트에는 포함되지 않음
