# (주)마이코젠 공식 홈페이지 + 편집 프로그램

**www.mycogen.co.kr** 에 올릴 정식 홈페이지와, 코드를 몰라도 내용·사진·페이지를 고칠 수 있는 **별도 편집 프로그램**입니다.
외부 패키지 설치가 필요 없고 **Node.js 하나만** 있으면 Windows·Mac 모두에서 동작합니다.

| 구분 | 내용 |
|---|---|
| 홈페이지 | 한국어(기본) + 영어, 11개 페이지 × 2개 언어 = 22쪽, 반응형(PC·태블릿·모바일) |
| 페이지 | 홈 · 회사소개 · 기술 · 사업분야(균사매트 배양 / 불연 바이오 건축자재 / 균사발효 대체육 / 균사발효 계란파우더) · 소식 · 문의하기 · 개인정보처리방침 |
| 편집기 | 브라우저에서 여는 로컬 프로그램. 실시간 미리보기, 사진 업로드(자동 압축), 섹션 추가·순서 변경, 되돌리기, 저장 기록, 배포용 ZIP |
| 검색 노출 | 페이지별 제목·설명, 네이버·구글 인증 코드 입력란, sitemap.xml, robots.txt, 한·영 hreflang, 공유 이미지(OG) |

---

## 1. 처음 한 번만: Node.js 설치

1. https://nodejs.org/ko/download 에서 **LTS** 버전을 내려받아 설치합니다(18 이상).
2. 이 `mycogen` 폴더를 PC에 내려받습니다.
   - GitHub 저장소 `kimyoonshik/mycelial-haven` → 브랜치 `claude/brave-dijkstra-6ezngf` → **Code → Download ZIP** 후 압축을 풀면 `mycogen` 폴더가 있습니다.

## 2. 실행 (편집기 / 홈페이지 보기)

| 하려는 일 | Windows | Mac |
|---|---|---|
| 내용 고치기 | `Mycogen-Editor-Windows.bat` 더블클릭 | `Mycogen-Editor-Mac.command` 더블클릭 |
| 완성 홈페이지 둘러보기 | `Mycogen-Homepage-Windows.bat` 더블클릭 | `Mycogen-Homepage-Mac.command` 더블클릭 |

검은 창이 뜨고 브라우저에 편집기(`http://127.0.0.1:4777`) 또는 홈페이지(`http://127.0.0.1:4777/site/`)가 열립니다. **검은 창을 닫으면 꺼집니다.** Mac은 처음 한 번만 우클릭 → 열기로 실행하세요.

한 번 실행하면 만들어지는 `dist\index.html`을 더블클릭해 열어도 모든 메뉴가 그대로 동작합니다.

### 화면 구성

```
┌ 상단 ─ 저장 상태 · 되돌리기/다시 · 변경 취소 · 저장(Ctrl+S) ───────────────┐
│ 왼쪽 메뉴        │ 가운데: 편집 양식                │ 오른쪽: 실시간 미리보기      │
│ 사이트 정보      │ 페이지 설정(제목·검색 설명·주소) │ KO/EN · PC/태블릿/모바일     │
│ 메뉴 구성        │ 섹션 카드(↑↓ 순서, 복제, 숨김,  │ 미리보기에서 영역을 클릭하면 │
│ 페이지 목록      │ 삭제) + 섹션 추가                │ 해당 섹션 편집으로 이동      │
│ 소식 · 미디어    │                                  │                              │
│ 저장 기록 · 게시 │                                  │                              │
└──────────────────────────────────────────────────────────────────────────────┘
```

- **글 고치기**: 모든 문구는 KO/EN 두 칸입니다. 영어 칸을 비우면 한국어가 대신 표시됩니다.
  `**굵게**`, `[문의하기](page:contact)`, `[사이트](https://…)` 형식으로 강조·링크를 넣을 수 있습니다.
- **사진 바꾸기**: 사진 칸의 `선택·업로드` → 끌어다 놓기. 큰 사진은 자동으로 2000px·WebP로 줄여 저장합니다.
- **섹션**: 히어로, 메시지, 카드 목록, 사진+글, 공정·단계, 숫자, 정보 표, 컬러 띠, 소식, 문의 유도, 문의 양식, 자유 글 — 12종을 페이지마다 자유롭게 조합합니다.
- **새 페이지**: 왼쪽 `+ 새 페이지` → 상위 페이지를 `사업분야`로 고르면 사업분야 메뉴·카드에 자동으로 들어갑니다.
- **저장**: 저장하면 `content/site.json`이 바뀌고 `dist/`(완성 사이트)가 새로 만들어집니다. 직전 내용은 `저장 기록`에 자동 보관(최근 80개)됩니다.

## 3. 홈페이지에 올리기(게시)

편집기 왼쪽 **게시·배포** 화면에 같은 안내가 있습니다.

1. 저장 → `배포용 ZIP 내려받기` (또는 `dist` 폴더 그대로 사용)
2. 호스팅에 업로드
   - **가비아·카페24 웹호스팅**: FTP로 `dist` 안의 파일 전체(`.htaccess` 포함)를 웹 루트(`www` 또는 `public_html`)에 올립니다.
   - **Netlify / Cloudflare Pages(무료)**: ZIP을 푼 폴더를 관리 화면에 끌어다 놓습니다.
3. 도메인 DNS에서 `www.mycogen.co.kr`을 호스팅으로 연결하고 SSL(https)을 켭니다.
4. 검색 등록 — 각 서비스에 사이트를 등록하고 인증 코드를 `사이트 정보 → 검색·공유`에 넣은 뒤 저장·재배포합니다.
   - **네이버 서치어드바이저**: 사이트맵 `https://www.mycogen.co.kr/sitemap.xml` + RSS `https://www.mycogen.co.kr/rss.xml` 제출
   - **구글 서치콘솔**: 사이트맵 제출 (Gemini·AI 개요도 구글 색인을 씁니다)
   - **Bing 웹마스터 도구**: 사이트맵 제출 (ChatGPT 검색·Copilot이 Bing 색인을 씁니다)
   - **Daum 웹마스터도구**: 발급된 `#DaumWebMasterTool:…` 문구를 그대로 입력
5. **SNS 연결**: `사이트 정보 → SNS·채널`에 주소를 넣으면 홈 첫 화면 오른쪽, 푸터, 모바일 메뉴, 문의 페이지에 아이콘이 생깁니다(주소를 넣은 것만 표시).

사이트를 만들 때 검색·AI용 파일이 자동으로 함께 생성됩니다: `robots.txt`(구글·네이버·다음·Bing과 ChatGPT·Claude·Gemini·Perplexity 등 AI 크롤러 허용), `sitemap.xml`, `rss.xml`, `llms.txt`(AI용 회사 요약), `llms-full.txt`(AI용 전체 본문), 페이지마다 구조화 데이터(회사·웹페이지·경로·소식, SNS 연결 포함).

### 사진
지금 들어 있는 사진은 ① 세이브어스 Mycerra 사이트의 자사 공정 사진(배양실·종균·균사 표면), ② 상업적 이용이 자유로운 CC0 사진(템페형 발효콩, 경석, 영지, 서리태), ③ 직접 제작한 계란파우더 일러스트입니다(출처: `content/CREDITS.md`).
다음 폴더의 실제 사진으로 바꾸면 완성도가 크게 올라갑니다.

- 균사매트: `E:\06_세이브어스\01_버섯균사체BIZ\01_05_은혜\균사사업 공유\01_참조자료\00_IR 제작용 각종사진`
- 경석 혼합 건축자재: `…\01_참조자료\zzz_경석혼합물 불연성 화염테스트`
- 대체육: `…\01_참조자료\03_대체육`

## 5. 폴더 구조

```
mycogen/
├─ Mycogen-Editor-Windows.bat / Mycogen-Editor-Mac.command       편집기 실행 파일
├─ Mycogen-Homepage-Windows.bat / Mycogen-Homepage-Mac.command   완성 홈페이지 보기
├─ content/
│  ├─ site.json          홈페이지의 모든 글·설정 (편집기가 이 파일을 고칩니다)
│  └─ media/             사진·파일 (uploads/ 에 새로 올린 파일)
├─ src/                  사이트 생성기 (schema · render · build · assets)
├─ editor/               편집 프로그램 (server.mjs + ui/)
├─ scripts/check.mjs     완성 사이트 링크 검사
├─ docs/                 레퍼런스 분석 문서
└─ dist/                 완성 사이트 (자동 생성, 업로드 대상)
```

## 6. 개발자용

```bash
npm run build     # content/site.json → dist/
npm run check     # 빌드 후 내부 링크·이미지 전수 검사
npm run editor    # 편집기 (http://127.0.0.1:4777)
```

- 섹션 종류와 입력 칸은 `src/schema.mjs` 한 곳에 정의되어 있고, 편집기 양식과 사이트 렌더러가 같은 정의를 씁니다. 새 섹션은 `SECTION_TYPES`에 항목을 추가하고 `src/render.mjs`의 `R.<type>` 함수를 만들면 됩니다.
- 편집기 서버는 `127.0.0.1`에서만 접속을 받으며, 외부 도메인에서 온 요청과 폴더 밖 경로 접근을 차단합니다.
- 레퍼런스(www.mycoiq.com)는 정보 구조와 분위기만 참고했고, 그 사이트의 글·사진·폰트·로고는 쓰지 않았습니다(`docs/reference-analysis.md`).
