# PC 정리 도우미 (PC-Care)

Windows 10/11에서 폴더를 정리하고, PC가 느려지는 원인을 찾아 정리하는 데스크톱 앱입니다.
`PC-Care.exe` 하나로 실행되며 설치가 필요 없습니다.

## 기능 (탭 6개)

| 구분 | 탭 | 하는 일 | 되돌리기 |
|---|---|---|---|
| 폴더 정리 | 폴더 정리 | 폴더 바로 안의 파일을 문서·이미지·동영상·음악·압축파일·설치파일 하위 폴더로 옮김 | '마지막 정리 되돌리기' 버튼 |
| | 중복 파일 | 내용이 똑같은 파일을 찾아 묶음마다 가장 오래된 1개만 남김 | 휴지통에서 복원 |
| 속도 개선 | PC 진단 | 디스크 공간, 메모리, CPU, 시작프로그램 수, 임시파일, 재시작 여부를 점검하고 원인별 조치를 안내 | 바꾸는 것 없음 |
| | 임시파일 정리 | 임시 폴더·Chrome/Edge 캐시에서 하루 넘게 지난 파일 삭제 | 불가 (지워도 되는 파일만) |
| | 시작프로그램 | 부팅할 때 자동 실행되는 프로그램을 끄고 켬 (작업 관리자 '시작 앱'과 같은 설정) | '켜기' 버튼 |
| | 무거운 프로그램 | 메모리·CPU를 많이 쓰는 프로그램을 보여 주고 종료 | 프로그램 다시 실행 |

## 안전장치

- 모든 정리는 **미리보기 → 선택 → 확인** 순서로만 실행됩니다. 앱이 혼자 지우는 일은 없습니다.
- 파일을 지우는 기능(중복 파일)은 **휴지통**으로 보냅니다. 임시파일만 바로 지우고, 이것도 하루가 지난 파일만 대상입니다.
- 중복 파일은 묶음의 파일을 전부 고르면 실행하지 않습니다(최소 1개는 남김).
- Windows 핵심 프로그램(explorer.exe, svchost.exe 등)은 종료할 수 없게 막혀 있습니다.
- 바로가기·숨김 파일·Office 임시 잠금 파일(`~$...`)은 옮기지 않습니다.

## 내려받기와 실행

1. GitHub 저장소의 **Actions** 탭에서 **PC Care (Windows build)** 의 가장 최근 초록색(✓) 실행을 엽니다.
2. 아래 **Artifacts** 의 `PC-Care-Windows` 를 눌러 내려받고 압축을 풉니다.
3. `PC-Care.exe` 를 원하는 폴더(예: `문서\PC-Care`)에 두고 더블클릭합니다.
   - 처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행** 을 누릅니다. (회사 인증서로 서명하지 않은 앱이라 뜨는 안내입니다)
   - '모든 사용자' 시작프로그램을 바꿀 때만 **마우스 오른쪽 버튼 → 관리자 권한으로 실행** 이 필요합니다.

## 기능 추가하기

앱을 다시 내려받지 않고 기능(탭)을 늘리거나 바꿀 수 있습니다.

1. 앱 오른쪽 아래 **추가 기능 폴더 열기** 를 누릅니다. (`PC-Care.exe` 옆에 `plugins` 폴더가 생깁니다)
2. 새 기능 파일(`.py`)을 그 폴더에 넣고 앱을 다시 켭니다. 탭이 하나 늘어납니다.
3. 기존 기능과 같은 `id` 를 가진 파일을 넣으면 그 기능을 새 버전으로 대신합니다.

새 기능 파일은 Claude에게 "PC 정리 도우미에 ○○ 기능을 추가해 줘"라고 요청하면 만들어 드립니다.
모양은 [`plugin_template.py`](plugin_template.py) 를 따릅니다. 새 기능이 앱에 없는 파이썬 라이브러리를 써야 하면
`requirements.txt` 에 추가해 `.exe` 를 다시 빌드합니다(푸시하면 GitHub가 자동으로 빌드).

## 기록 파일

`%LOCALAPPDATA%\PCCare\` 에 저장됩니다.

- `pc-care.log`: 오류 기록 (문제가 생기면 이 파일을 보내 주세요)
- `organize-undo.json`: 마지막 폴더 정리 기록 (되돌리기에 사용)

## 개발자용

```bash
cd pc-care
python -m pip install -r requirements.txt pytest
python -m pytest -q          # 테스트
python run.py                # 소스에서 실행
python run.py --selftest out.txt   # 모든 탭을 열어 보고 결과를 out.txt 에 쓴 뒤 종료
```

- 기본 기능은 `pc_care/plugins/` 에 있고, 하나의 파일이 하나의 탭입니다. 새 기본 기능은 파일을 추가하고 `pc_care/plugins/__init__.py` 의 `BUILTIN` 에 넣습니다.
- 공통 도구(표, 폴더 선택, 백그라운드 작업, 휴지통 보내기 등)는 `pc_care/plugin_api.py` 에 있습니다.
- `pc-care/` 나 빌드 설정(`.github/workflows/pc-care.yml`)이 바뀌어 푸시되면 GitHub가 Windows에서 테스트 → 모든 탭 열기 → `.exe` 빌드 → 빌드된 `.exe` 로 다시 모든 탭 열기(견본 추가 기능 포함)를 거쳐 `PC-Care-Windows` 를 만듭니다.
